# hxyfront-62003 法医昆虫学样本记录

源提示词编号：5

法医昆虫学样本记录前端工具：记录采样地点、环境温度、尸体暴露阶段、昆虫种类、发育阶段、采样时间、保存方式和鉴定备注，包含样本批次列表、发育阶段筛选、温度记录图、案件样本关联页和单个样本详情卡片。

本次新增 **虫龄序列编排** 工作流。

## 虫龄序列规则

1. **挑样本**：鉴定人在同一案件下挑出至少两枚样本，界面先按采样时间升序排列预览。
2. **拒绝条件**：不足两枚、**虫种不同** 或 **采样时间相同**（无法确定先后）时拒绝编排，并给出具体原因；拒绝留痕持久保存。
3. **待补 / 送复核**：虫种一致且时间互异时建立序列；地点、温度、保存方式三项有任一缺失则存为「待补」，三项齐全送入「复核」。
4. **原样本不丢**：序列只保存样本 ID 引用；在样本详情卡片补录地点/温度/保存方式后，待补序列自动解除待补、送入复核。
5. **复核**：发育阶段必须沿 **卵 → 幼虫 → 蛹 → 成虫** 前进（允许同阶段停留），出现倒退即「退回」，并在 `lastReview` 中保留上次复核的阶段快照与历史记录；鉴定人修正阶段后可重新复核。
6. **联动更新**：阶段筛选、温度曲线、案件关联页与序列工作台共用同一份本地数据，任一编辑各处同步。
7. **持久化**：数据保存在 `localStorage`（key：`forensic-entomology-records-v1`），关闭重开页面可接着处理；顶部「重置本地数据」可恢复演示数据。

## 目录说明

- `src/domain.ts`：编排与复核的纯函数规则（拒绝判定、缺项、阶段倒退检测）
- `src/store.ts`：React 状态管理 + localStorage 持久化
- `src/seed.ts`：演示数据（含齐全序列、缺项、虫种不同、时间相同、阶段倒退等场景）
- `src/components/`：样本批次 / 虫龄序列 / 案件关联 / 温度曲线图 / 通用组件

## 技术栈

React 19 + Vite 7 + TypeScript（严格模式），无额外运行时依赖；温度曲线为纯 SVG。
