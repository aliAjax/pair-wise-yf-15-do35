# hxyfront-62003 法医昆虫学样本记录

源提示词编号：5

做一个法医昆虫学样本记录前端工具，用来记录采样地点、环境温度、尸体暴露阶段、昆虫种类、发育阶段、采样时间、保存方式和鉴定备注。页面需要有样本批次列表、发育阶段筛选、温度记录图、案件样本关联页和单个样本详情卡片。

## 技术栈

React + Vite + TypeScript

## 本地运行

```bash
npm install
npm run dev
```

开发端口：62003

## 虫龄序列编排规则

- **编排**：鉴定人挑出同一案件至少两枚样本；虫种不一致、分属不同案件或采样时间相同都会被拒绝并显示原因，通过后按采样时间升序成链。
- **待补**：序列成员的采样地点、环境温度、保存方式缺一即存为「待补」，逐项定位缺失字段；原始样本始终保留、不删除不覆盖。
- **复核**：补齐后送入复核，逐枚核对发育阶段；阶段只能沿 卵 → 幼虫 → 蛹 → 成虫 前进（同阶段并列允许），出现倒退即退回并写明位置，退回不覆盖样本，且保留上次通过快照与完整复核历史。
- **联动与持久化**：阶段筛选、温度曲线（SVG 多案件曲线）、案件关联页随样本/序列实时联动；数据保存在 `localStorage`，重开页面可接着处理，也可一键恢复演示数据。
